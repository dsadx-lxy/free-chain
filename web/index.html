参数与结果

链由 n 个长度为 l 的链段自由连接，无键角限制、无位阻。 均方末端距 ⟨h²⟩ = n·l²，即 h = l√n。 结果的长度单位就是 l 的单位 —— l 填 1 nm，答案就是 nm。

当前是自回避行走：链在立方格点上走，每步六选一，但同一个格点不许重复访问。 这条约束把 ⟨R²⟩ 从 n·l² 推到 n^(2ν)， 而 ν 没有闭式解、只能采样着测 —— 所以这一页只留下这个模型真正算得出来的东西，其余卡片都收起来了。

标度验证

两件互不相干的验证：⟨R²⟩ 是不是真按 n 线性长（下面那张扫描）， 以及高斯链的熵弹性在多大范围内够用（上面这张力–伸长）。 另外，链模型选到受阻旋转链或蠕虫状链时， 这一节末尾还会多出一张能量图景 —— 四个模型里只有这两个有真正的 能量自由度（内旋转势垒、弯曲刚度），另外两个没有势可画。

验证的题目换了一个：本模型没有闭式解，「斜率是不是 1」这条判据问不出来， 要问的是实测指数是不是 2ν = 1.175 —— 下面这张图把模拟点、斜率 1 的理想链参考线、斜率 2ν 的参考线画在一起。

力–伸长曲线

λ = L(x)　Langevin（精确） λ = x/3　高斯链（只到 x = 3）

横轴是无量纲力 x = f·l/(k_BT)，纵轴是归一化伸长 λ = ⟨x⟩/(n·l)。这条曲线与 n、 l 都无关 —— Langevin 函数里没有它们； n、l 只在换算成绝对伸长和 pN 时才进来。 小力下两条线重合（λ ≈ x/3，正是高斯链的熵弹性）， 分开了就说明高斯近似开始失效。鼠标悬停可读 x、λ、力（pN）与绝对伸长。

链长扫描：链变长时末端距怎么变

双对数坐标下 ⟨R²⟩ = n·l² 是一条斜率恰为 1 的直线：这条线直不直、 斜率是不是 1，就是该公式的数值证据。每个 n 采 M 条独立链，M 越大点越贴近理论线。 这是一次统计测量，不点「运行模拟」就不会算。鼠标悬停圆点可读数，聚焦后按 ←/→ 逐个看。

自回避行走：⟨R²⟩ 还正比于 n 吗

自回避行走是立方格点上的一步一格、同一个格点不许走第二次的随机行走 （格点常数就是 l，与顶部参数行共用）。 同格点的理想链每步 6 选 1、不管走没走过，⟨R²⟩ = n·l² 精确成立 —— 所以图上那条斜率 1 的直线是理想链，而模拟点会明显跑到它上方： 这就是溶胀，链被迫比理想链舒展，因为回头会撞上自己。 渐近地 ⟨R²⟩ ∝ n^(2ν)，文献值 2ν = 1.175194（虚线）。 但这片 n 区间（≤ 30）测出来的斜率约 1.19–1.22，是偏高的：有限尺寸修正的符号 在这个窗口里为正，渐近值要 n 很大才到 —— 所以上面报的是「这片区间的有效 ν」， 不是「测出了 0.588」。这一条不是采样出错，是短链的真实现象。也因此上面那条虚线 和拟合直线几乎重合（只差百分之一点几）—— 这两条线分不分得开不是判据， 那个 σ 数才是。 每个 n 采 M 条独立链，点上的小竖线是每个 n 各自实测的 ±2σ 涨落。 鼠标悬停圆点可读数，聚焦后按 ←/→ 逐个看。

模型指纹

方向关联：隔 k 个链段以后，两个键还指得多一致。 自由连接链隔一段就彻底不相关（直接掉到 0）、自由旋转链按 cosθ 逐段衰减、 受阻旋转链是「先升后抖」（内旋转把平面朝向也带进了关联）、 蠕虫状链衰减最慢 —— 衰减长度就是持久长度。四个模型的差别全从这里来。

Cn 随链长的收敛：横轴是链段数 n（对数）， 虚线是长链极限 C∞。有限 n 时的 Cn 总是更小，差的那一项是 O(1/n) —— 教科书那个数只在长链极限下才出现，别把有限 n 的值当成算错了。

能量图景

内旋转势的 U(φ) 曲线与三态布居：左图是 势，右图是布居，两张图画的是两件事。 采样器只抽 φ = 0°（trans）与 ±120° （gauche）这三个离散值 —— 所以右图是三根柱，不是一条分布曲线。 左图那条三井曲线，井底正好落在那三个态上（三个点就是），两个井底的高度差就是 ΔE/kT = ln((1+2⟨cosφ⟩)/(1−⟨cosφ⟩))。它不是 120° 周期的：井底间距是 120°、三口井一样深，但两条势垒不一样高 （trans↔gauche 那条恒比 gauche↔gauche 那条低），而 120° 周期会强制它们一样高 —— 整条曲线是 360° 周期的。 有三件事要如实说明：第一，井底位置与井深是模型的预言，势垒高度是画法 约定 —— 模型只给了 ΔE 这一个数，要画一条曲线还得另外定它多高，本图取的是 「两个 gauche 井之间 = 4|ΔE|」，换个约定曲线会变高变矮， 而三个井底一动不动；第二，对这条连续曲线做玻尔兹曼积分 得到的权重，与右图那三根柱不是同一个数（三态是离散近似）， 曲线说的是「ΔE 是从哪来的」，不是「采样器在按它抽」； 第三，⟨cosφ⟩ = 0 时这条曲线是精确的平线 （两个系数一起归零），那一点上受阻旋转链与自由旋转链精确重合 —— 平线不是画不出来，是那里真的没有位阻。 另有两处：⟨cosφ⟩ → 1 时几乎全 trans（井越来越深）， ⟨cosφ⟩ = −1/2 时 ΔE 真的是 −∞， 曲线用截断值 −3 kT 画 —— 真值画不出来，但方向是对的 （0° 那个井被抬到两个 gauche 井上面，而不是整条翻过来）；文献常把 trans 画在 180°、gauche 画在 ±60° （与本图的 0°/±120° 只差一个 180° 平移，是同一个东西）。 还有链上第一个二面角没有参考平面，采样器对它取的是均匀分布， 所以右图那种三态布居描述的是第二个键往后的每一段。

特征比 Cn 随位垒：横轴是 gauche 相对 trans 的能量差 ΔE/kT = ln((1+2⟨cosφ⟩)/(1−⟨cosφ⟩))（纵轴对数）。 位垒越高、trans 越占优，链越僵硬、Cn 越大。三个锚点： ΔE = 0 处 Cn 正好等于该键角下自由旋转链的值 （三态等权重 ⇒ 绕键自由旋转）；ΔE = ln4 ≈ 1.386 kT 是聚乙烯 （⟨cosφ⟩ ≈ 0.5，正是经典的位阻因子 4），Cn ≈ 6， 对上实测的 C∞ ≈ 6.7；往左到 −∞（全 gauche）则 Cn 落到自由旋转链的 1/3。曲线本身是逐点回内核的 Cn 公式现算的，不是拟合。

弯曲势与它给出的键角分布：左图是 U(cosθ)/kT = κ(1 − cosθ) —— 相邻键对齐时能量为 0、 完全反向时是 2κ，κ 就是「弯一下要花多少 kT」。 右图是同一个势的玻尔兹曼分布 p ∝ e^(κ·cosθ)，竖线标出它的均值 ⟨cosθ⟩ = L(κ) = e^(−l/p)。 这不是巧合：采样器抽的那步逆变换就是从这个分布来的，所以右图和左图是 同一件事的两种画法。κ 越小分布越平，κ → 0 时退化成均匀分布 —— 蠕虫状链在那里退回自由连接链。竖线位置与「模型指纹」卡的 方向关联第一项是同一个数，两处可以对上。

持久长度随弯曲刚度：两条轴都是对数。 界面上填的是持久长度 p，κ 是由它反解出来的 （解 L(κ) = e^(−l/p)，二分到机器精度）—— 所以这条曲线 也是内核那条公式本身，不是拟合。虚线是渐近式 κ ≈ p/l + 1/2：p/l 大时两条线几乎重合， 所以「κ 就等于 p/l」在刚性链上够用；p/l 接近 1 时 它开始偏，那半项不能丢 —— 两条线分家的地方，正是那个直觉失效的地方。
